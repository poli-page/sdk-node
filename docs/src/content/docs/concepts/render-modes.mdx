---
title: Render input
description: Every render method takes one input type, a project and template by slug, rendered from the copy published in the key's environment.
---

Every render method (`render.pdf`, `render.pdfStream`, `render.document`, and the `renderToFile` helper) takes the same input type, `RenderInput`: a project and one of its templates, by slug, plus the `data` that fills the template.

## The input

```ts
const pdf = await client.render.pdf({
  project: 'billing',
  template: 'invoice',
  data: { invoiceNumber: 'INV-001', total: 1280 },
});
```

- `project`, `template`, `data` — required.
- `format`, `orientation`, `locale`, `metadata` — optional; an unset field is not sent.
- `signal`, `idempotencyKey` — per-call options; not part of the request body.

The SDK sends only these fields. A field the API does not know, such as `version`, is a compile-time error in a TypeScript object literal; passed through a variable, or from untyped JavaScript, it compiles and is dropped, never sent.

## Which copy is rendered

The API resolves the environment from the API key and renders the project's copy published in that environment. There is no version to pick, and no key renders the draft: publish the project to the key's environment first. A project that is not published there gets `404 PROJECT_NOT_IN_ENVIRONMENT`.

Templates live in your project, so anyone with dashboard access can edit and publish them without touching code. To preview a template or render inline HTML while you design it, use the playground: [play.poli.page](https://play.poli.page).

## Example

```ts
import { PoliPage } from '@poli-page/sdk';

const client = new PoliPage({ apiKey: process.env.POLI_PAGE_API_KEY! });

const invoicePdf = await client.render.pdf({
  project: 'billing',
  template: 'invoice',
  data: { invoiceNumber: 'INV-001', total: 1280 },
  format: 'A4',
  locale: 'en-US',
  metadata: { customerId: 'cust_123' },
});
```
