This page walks through your first render — from key to PDF — without touching the dashboard. Every organization gets a `getting-started` project, published into its `sandbox` environment when the organization is created, with a `welcome` template; a `sandbox` key renders it with no setup.

<ApiKeyCallout />

## Set your API key

Create a `sandbox` key in a fresh organization and export it into the environment your script runs in:

```bash
export POLI_PAGE_API_KEY=pp_sandbox_x   # replace with your sandbox key
```

`getting-started` is a normal, editable project: in an organization that renamed it, deleted it or removed it from `sandbox`, the API answers `404 PROJECT_NOT_FOUND` or `404 PROJECT_NOT_IN_ENVIRONMENT`. Use a fresh organization to follow along.

## Render a PDF

```ts
import { PoliPage } from '@poli-page/sdk';

const client = new PoliPage({ apiKey: process.env.POLI_PAGE_API_KEY! });

const pdf = await client.render.pdf({
  project: 'getting-started',
  template: 'welcome',
  data: { name: 'SDK Demo' },
});
```

`pdf` is a `Uint8Array`. Write it to disk, stream it to S3, or return it directly from an HTTP handler. Sandbox renders are watermarked and do not count toward your monthly PDF quota.

To render your own templates, publish the project to the environment of the key you render with, then swap the slugs. To preview a template or render inline HTML while you design it, use the playground: [play.poli.page](https://play.poli.page).

## Example

```ts
import { writeFile } from 'node:fs/promises';
import { PoliPage } from '@poli-page/sdk';

const client = new PoliPage({ apiKey: process.env.POLI_PAGE_API_KEY! });

const pdf = await client.render.pdf({
  project: 'getting-started',
  template: 'welcome',
  data: { name: 'SDK Demo' },
});

await writeFile('./welcome.pdf', pdf);
```
